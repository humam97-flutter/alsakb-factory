# نظام معمل السكب الحديدي

نظام لإدارة معمل السكب الحديدي، بالعربي، ويشتغل على الموبايل والحاسبة. المرحلة الأولى تشمل:

- **أوامر العمل**: المراحل (قص، ثني أو درفلة، لحام، صبغ، فحص، تسليم)، المكائن، المسؤول، ورقة شغل للطباعة.
- **المخزن**: المواد، الصرف على أوامر العمل، الاستلام، الجرد. الرصيد يتحدث تلقائياً من الحركات.
- **الكلفة والربح**: المواد المصروفة + الأجور + التشغيل + كلف أخرى، مقابل سعر البيع والمستلم.
- **المكائن والصيانة**: حالة كل ماكنة، الأعطال، سجل الصيانة. المكائن الـ19 مُدخلة مسبقاً.
- **العمال والرواتب**: الحضور اليومي، الساعات الإضافية، السلف والمكافآت والخصومات، كشف الراتب الشهري.
- **المستخدمون والصلاحيات**: الدخول برقم الهاتف، وخمسة أدوار.

| الدور | يقدر |
| --- | --- |
| المدير | كل شي |
| مدير الإنتاج | أوامر العمل، المكائن، العمال، الحضور. بدون أسعار أو أجور |
| أمين المخزن | المواد وحركات المخزن |
| المحاسب | أسعار الأوامر، الأجور، الرواتب والدفعات |
| مشغل / عامل | يحدّث حالة المراحل ويبلّغ عن الأعطال |

الصلاحيات مفروضة داخل قاعدة البيانات نفسها (Row Level Security)، مو بس بالواجهة.

## التقنية

- **Next.js 15** (React) مع Server Actions
- **Supabase**: قاعدة بيانات PostgreSQL، الدخول، والصلاحيات
- يُنشر على **Vercel**

## التشغيل لأول مرة

1. **Supabase**: افتح حساباً على [supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً (اختر منطقة Frankfurt لأنها الأقرب للعراق).
2. **قاعدة البيانات**: من SQL Editor في Supabase، شغّل الملفين بالترتيب:
   - `supabase/migrations/0001_init.sql`
   - `supabase/migrations/0002_seed_machines.sql`
3. **إعدادات الدخول**: في Authentication → Providers → Email، أطفئ «Confirm email» (الحسابات ينشئها المدير، وما تحتاج تأكيد).
4. **المفاتيح**: انسخ `.env.example` إلى `.env.local` واملأ القيم من Project Settings → API.
5. **أول مدير**:
   ```bash
   npm install
   node --env-file=.env.local scripts/create-manager.mjs "اسمك" 07XXXXXXXXX كلمة_السر
   ```
6. **التشغيل محلياً**: `npm run dev` ثم افتح http://localhost:3000
7. **النشر**: اربط المستودع بـ [Vercel](https://vercel.com) وأضف نفس المتغيرات الثلاثة في Environment Variables.

بعد الدخول كمدير، أضف باقي الموظفين من صفحة «المستخدمون».

## التثبيت على الموبايل

افتح الموقع من Chrome على أندرويد واختر «إضافة إلى الشاشة الرئيسية»، أو من Safari على iPhone: مشاركة ← «إضافة إلى الشاشة الرئيسية».

## بنية الكود

```
app/login              تسجيل الدخول
app/(app)/             الشاشات بعد الدخول
  orders/              أوامر العمل والمراحل وورقة الشغل
  stock/               المواد وحركات المخزن
  machines/            المكائن
  maintenance/         الأعطال والصيانة
  workers/             العمال والحضور
  payroll/             الرواتب والدفعات
  users/               المستخدمون (للمدير)
lib/                   الدخول، الصلاحيات، التسميات العربية
supabase/migrations/   قاعدة البيانات والصلاحيات
```
